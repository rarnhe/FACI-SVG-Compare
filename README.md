# OneThreeOctave-SVG-Compare

以 XLSX 为二维 CAD 空间数据输入，使用 Three.js 在同一交互界面中展示 **Fab / Subfab** 两个联动的图纸，右侧显示 PSD 与 1/3 倍频程参考 SVG。现有 Bokeh Server 仍可通过 `/analysis` 独立访问。

## 启动

在仓库根目录安装依赖：

```bash
python -m pip install -r requirements.txt
```

从仓库**父目录**启动：

```bash
python -m OneThreeOctave-SVG-Compare
```

或进入仓库根目录执行 `python __main__.py`。启动时输出 XLSX 图纸坐标和对象文字，并打开 `/viewer/index.html?rev=...`。

### assets 文件

```text
assets/
├── luoD.xlsx
├── PSD_base.svg
└── 1-3-Octave_base.svg
```

请将旧的 `OneThreeOctave_base.svg` **在本地改名为 `1-3-Octave_base.svg`**。实际 XLSX 与 SVG 尚未提交到仓库，自动化测试使用临时样本。

**严格输入约束：**

- `assets/` 不存在 XLSX 时可启动空白 CAD 和 SVG 页面。
- 若存在 XLSX，则整个 `assets/` **只能存在一个有效 .xlsx**；忽略 `~$` 等 Excel 临时文件。
- 该 XLSX 必须包含**恰好两个 Sheet**：第一个为 Fab、第二个为 Subfab。
- **每个 Sheet 必须恰好包含一张 DrawingML 图片**；0 张或超过 1 张会停止启动并显示错误。
- 图片只读、按需从 XLSX ZIP 中提取；原始 XLSX 文件不通过 HTTP 暴露。

## CAD 坐标与联动

`xlsx_spatial.py` 仍返回以 A1 左上角为原点的 `bounds_emu` 和 `vertices_px`；`cad_service.py` 再将**每个 Sheet 的底图左上角移到局部 (0,0)**，所有形状同步减去该 Sheet 图片的坐标偏移。这样 Fab 和 Subfab 通过各自的图纸原点使用统一的相机位置、朝向和缩放，不受原始单元格排版起点影响。

- 滚轮：两层同步缩放。
- 右键拖动：两层同步平移。
- 左键拖动：两层同步旋转。
- 两个 CAD 区域均采用**Excel 内嵌 PNG 底图**，用图片原始宽高比显示；上下图宽度规范到共同的 CAD 参考宽度，左右/上下形状位置跟随图片进行坐标变换，保持两层共同相机比例尺，不拉伸背景图片。
- 仅上方 Fab 左上角显示带圆角边框的鼠标提示「滚轮缩放·右键拖动平移·左键拖动旋转」。
- **文本框仅作为视觉与层级提示，不参与点击命中。** 矩形等普通形状使用左键短按选中；椭圆只允许右键短按选中；右键拖动依旧平移，不弹出菜单。
- 鼠标**移至可选图元上方**，在所属层左下角的圆角提示框按几何包含链显示 `工作簿名（不含.xlsx）·Sheet 名·父级文本框/形状·当前形状`。移到空白或非特殊图元上立即隐藏；两层互不干扰。
- 右键选中椭圆时，后台从其**父级文本框文字同名的 assets 子目录**提取 SVG 文件名中的 `_14位数字_` 标签并去重排序为一级菜单；选日期后，X/Y/Z 作为**向右弹出的二级菜单**。
- 点击方向后，按**圆形所属矩形的文字/名称 + 日期 + +X/+Y/+Z** 严格匹配成对 SVG，要求分别以 `_PSD.svg`、`_1-3-Octave.svg` 结尾。只有两张均存在且可加载才一起更新右侧；新增可鼠标左键拖动、直角边框、内容按最长文本定宽的浮动选择记录，重复选择逐行增加高度。
- **↺：只恢复平面俯视方向**，保留当前缩放倍数与平移中心，不再自动重新展示全景。

### Excel 形状类型

`xlsx_spatial.py` 优先根据 DrawingML 的 `prstGeom` / `txBox` 确定图形类型，必要时按 Excel 对象名称回退：

- **文本框**：严格使用 XLSX 图形自己的填充/边框/文字颜色，保留显示但不能选中。
- **椭圆**：按图形外框两条对角线交点取圆心，以左上至右下对角线为直径，绘制**可点击圆形**。使用重构圆的真实边界（不是中心点）判定与旋转矩形的关系：**整圆在内部 → Z=矩形顶面高度；与唯一矩形部分相交/切触 → Z=0.5×矩形高度；全部在外部 → Z=0**。如果一个圆碰到两个或以上矩形，启动时直接报错终止。
- **矩形**：只解析 DrawingML 非可视属性 `cNvPr@descr`（替换文字；为空时回退 `title`），兼容 Excel 的 `_x000D_` 转义。写成 `z=0.5x` 时长方体高度 = X 宽度 × 0.5；`z=0.1y` 时高度 = Y 高度 × 0.1。可见文字 `B1_x0.5` 不再决定高度。替换文字不存在或无效则**不绘制长方体**，保留可见、可点击的平面图元。同一 Sheet 仍禁止面积重叠的矩形，允许仅共边/顶点。
- **椭圆的 Z 定位**：椭圆中心落在某个矩形的旋转后二维占地区域时，将椭圆平面抬升到该矩形的 Z 顶部；重叠矩形取**最高的顶部**。圆形仍可被 Raycaster 点击。
- 其余对象保留原来的平面覆盖层。

形状文字独立测量实际 Canvas 文本宽高，并**等比例缩小**以适应形状大小，不再把一张定宽/定高纹理拉伸到矩形。文字位于对象左上角，边框、颜色与旋转继续依照 XLSX 属性。

## 页面可调分割

左侧 CAD 与右侧 SVG 之间的**竖向分割条**可拖动，两侧容器实时改变大小；右侧两幅 SVG 中间的**横向分割条**也可拖动，调整上下区域高度。均支持键盘方向键微调。

右侧默认 SVG 仍为 `PSD_base.svg` 与 `1-3-Octave_base.svg`，保持居中、等宽、原始比例；一级菜单日期和二级 X/Y/Z 对应的 SVG 可同时覆盖这两个位置。首次加载的上下高度比例固定 **5.8:18.1**。拖动左右或上下分隔条时，先以当前两张图的实际显示宽度与高度限位，不允许拖动到产生横向滚动条的位置；尺寸随可用区域动态计算，无任意固定的图片最大宽度。右侧选择记录浮动框可拖动，显示例如 `20260704_SCN_B1_20260704101627_+X`。

## 双轨验证

```bash
python tests/run_tests.py
```

与 `.github/workflows/test.yml` 使用相同的 unittest 测试组，分别由 Ubuntu/Python 3.12 和 Windows/Python 3.14 运行，并验证 `cad_viewer.js` 的模块语法。新增 XLSX alt/title 属性测试、BODYv2 子目录时间戳与成对图片安全匹配测试、图像比例尺与分隔条限位测试。测试覆盖图纸解析、零点转换、图片唯一性、形状分类、矩形 X/Y 高度后缀、旋转矩形面积重叠校验、圆与矩形的完全包含/部分相交/完全分离及多矩形相交终止、网页静态资源、两处拖动布局和 Bokeh 旧接口。另使用 `node --test tests/test_cad_geometry.mjs tests/test_cad_ui.mjs` 对实际浏览器共享的几何、层级选中与响应式 SVG 适配算法执行独立 JS 单元测试。通过与失败都自动生成并上传 `test_report.md`；main 的自动报告回写不会再次触发 CI。

**真实 XLSX 图纸的图元与两张 SVG 的显示效果仍需要 Windows 浏览器视觉验证**，CI 无法代替实际资源检查。
