# OneThreeOctave-SVG-Compare

以 XLSX 为二维 CAD 空间数据输入，使用 Three.js 在同一交互界面中展示 **Fab / Subfab** 两个联动的图纸，右侧显示 PSD 与 1/3 倍频程参考 SVG。现有 Bokeh Server 仍可通过 `/analysis` 独立访问。

## 启动

在仓库根目录安装依赖：

```bash
python -m pip install -r requirements.txt
```

从仓库**父目录**启动：

```bash
python -m OneThreeOctave-SVG-Compare
```

或进入仓库根目录执行 `python __main__.py`。启动时输出 XLSX 图纸坐标和对象文字，并打开 `/viewer/index.html?rev=...`。

### assets 文件

```text
assets/
├── luoD.xlsx              # 两个 Sheet 各有一张内嵌图片，直接作为左侧背景
├── PSD_base.svg           # 右侧 PSD 参考底图
└── 1-3-Octave_base.svg    # 右侧倍频程参考底图
```

请将旧的 `OneThreeOctave_base.svg` **在本地改名为 `1-3-Octave_base.svg`**。实际 XLSX 与 SVG 尚未提交到仓库，自动化测试使用临时样本。

**严格输入约束：**

- `assets/` 不存在 XLSX 时可启动空白 CAD 和 SVG 页面。
- 若存在 XLSX，则整个 `assets/` **只能存在一个有效 .xlsx**；忽略 `~$` 等 Excel 临时文件。
- 该 XLSX 必须包含**恰好两个 Sheet**：第一个为 Fab、第二个为 Subfab。
- **每个 Sheet 必须恰好包含一张 DrawingML 图片**；0 张或超过 1 张会停止启动并显示错误。
- 每个 Sheet 的单张 DrawingML 图片**作为左侧对应 CAD 分栏的真实背景**。服务端按需通过只读 `/viewer/cad-image/<层号>/<图片序号>` 提取该 PNG/JPG 等媒体，限制文件类型和解压后大小，客户端读取图片的真实像素宽高比。该图片在 XLSX 内的锚点左上角仍是形状坐标原点；原始 XLSX 文件不通过 HTTP 暴露。无需额外准备与 Sheet 同名的 SVG 背景。

## CAD 坐标与联动

`xlsx_spatial.py` 仍返回以 A1 左上角为原点的 `bounds_emu` 和 `vertices_px`；`cad_service.py` 再将**每个 Sheet 的底图左上角移到局部 (0,0)**，所有形状同步减去该 Sheet 图片的坐标偏移。这样 Fab 和 Subfab 通过各自的图纸原点使用统一的相机位置、朝向和缩放，不受原始单元格排版起点影响。

- 滚轮：两层同步缩放。
- 右键拖动：两层同步平移。
- 左键拖动：两层同步旋转。
- 两个 CAD 区域各自使用**XLSX Sheet 内嵌图片**作为背景。先解码图片，再依据 `naturalWidth/naturalHeight` 获取图片的**真实长宽比**；无法读取时仅以 XLSX 图片锚点宽高比作为几何回退（不使用 Sheet 同名 SVG）。上下两栏以**共同的世界坐标图片宽度**保持两层相机缩放一致；每张图片的显示高度 = 共同宽度 × 图片真实高宽比。图片、文本框、矩形、椭圆**全部通过同一层的 X/Y 变换**，使各个图元在背景中的相对位置与 Excel 中一致，同时图片本身不被拉伸变形。
- 仅上方 Fab 左上角显示带圆角边框的鼠标提示「滚轮缩放·右键拖动平移·左键拖动旋转」；与右上 ↺ 同为白色背景、14px 字号、36px 高，顶部对齐。Fab 与 Subfab 中间添加 8px、与主分隔条同色的固定横线（不可拖动）。
- **文本框仅作为视觉与层级提示，不参与点击命中。** 矩形等普通形状使用左键短按选中；椭圆只允许右键短按选中；右键拖动依旧平移，不弹出菜单。
- 鼠标**悬停文本框、矩形或测点**，左下角按实际几何包含关系显示 `**BODYv2**·20260704_SCN_B1·测点名称`（第一项文本框加粗）。不再显示工作簿与 Sheet 名；移到空白隐藏。文本框仅参与悬停，不参与鼠标点击选中。
- 右键选中椭圆时，后台只扫描其**父级文本框文字同名的 assets 子目录**。若重建的圆完全处于某一矩形内部，则必须在**同一 SVG 文件名**中同时匹配该矩形的可见文字和 `_14位数字_` 时间戳；若椭圆处于矩形外部（但位于文本框内），则要求在同一文件名中同时匹配**父级文本框文字**与时间戳（legend 仍显示测点文字）。匹配后的时间去重、升序排列为一级菜单，不符合当前测点的文件不贡献日期。找不到匹配日期时显示「无可用测试结果」。点击日期后，二级 **X / Y / Z 纵向排列**，向右展开（空间不足时向左）。
- 点击方向后，按**当前矩形文字（矩形内）／父级文本框文字（矩形外） + 日期 + +X/+Y/+Z** 严格匹配成对 SVG。浮动 legend 的**可见名称**固定为 `文本框名称_Sheet名称_矩形名称或测点名称_+方向`，例如 `BODYv2_fab_20260704_SCN_B1_+Y`，不显示时间戳；内部仍包含时间戳以区分同一测点不同时刻的 SVG 图层。浏览器**只读请求一次原始 SVG 并缓存其内容**；每次新增的 PSD 与 1-3-Octave 叠加图在浏览器内存中按指定 **17 色调色板顺序轮播**，两张图使用同一种颜色，相邻两次添加使用不同颜色。通过 DOMParser 在内存中修改显式 stroke/fill，再生成临时 Blob URL 供 <img> 使用；保留无填充、透明和渐变定义，不再修改/保存 `assets/` 中的 SVG，也**不再向 Python 服务发起写入请求**。legend 每项为 **14px 粗体同色文字，无图标**；重复项目不再加载。legend 右键只显示「颜色 › / 退出」，颜色二级菜单在右侧纵向列出 17 色；修改颜色仅替换该项两张图片的内存 Blob URL，退出仅关闭该项并释放资源。
- **↺：只恢复平面俯视方向**，保留当前缩放倍数与平移中心，不再自动重新展示全景。

### Excel 形状类型

`xlsx_spatial.py` 优先根据 DrawingML 的 `prstGeom` / `txBox` 确定图形类型，必要时按 Excel 对象名称回退：

- **文本框（恢复文字显示）**：读取 XLSX DrawingML 的富文本段落（`a:p` / `a:r`），恢复每段文字的**字体、字号（百分之一磅）、颜色（含主题配色）、粗斜体**，及 `a:bodyPr` 的内边距、垂直锚点与 `a:pPr` 的水平对齐。用透明 `CanvasTexture` 把文字绘制在对应文本框平面上，随其**位置、尺寸及旋转角度**同步变化；画布沿用背景图片的 X/Y 坐标比例尺。文本框填充与边框颜色继续使用 XLSX 原始 `spPr` / `ln`，明确无边框时不额外绘制。文本框仍不参与点击选中，其文字也继续用于左下角悬停提示及 SVG 目录定位。
- **椭圆**：按图形外框两条对角线交点取圆心，以左上至右下对角线为直径，绘制**可点击圆形**。使用重构圆的真实边界（不是中心点）判定与旋转矩形的关系：**整圆在内部 → Z=矩形顶面高度；与唯一矩形部分相交/切触 → Z=0.5×矩形高度；全部在外部 → Z=0**。如果一个圆碰到两个或以上矩形，启动时直接报错终止。
- **严格绘制层级**：左侧每个 CAD 层内按 `底图 → 文本框 → 矩形 → 椭圆` 的顺序合成，即使 XLSX 图元存储顺序不同也一致。通过 `cadShapeZOffset()` 将文本框放在 XY 下方，并为椭圆保留矩形顶面抬升高度；`cadShapeRenderOrder()` 对所有图元的透明材质排序，使旋转视角下仍保持椭圆在最上。文本框颜色与透明填充不变。
- **长方体实体与边线**：具有正高度的矩形使用 `THREE.BoxGeometry` 绘制实体面，**正常状态不透明度 93%、选中状态 100%**（非 `wireframe` 材质）；同时通过 `EdgesGeometry` 建立 12 条立体轮廓边线，颜色**直接读取矩形在 XLSX 中的轮廓色**。视角旋转时仍可以清晰辨认立体形态；若 Excel 边框明确设为无/透明，则不凭空生成轮廓。矩形无有效高度时继续显示原来的平面边框，椭圆图层仍在其上。
- **矩形**：只解析 DrawingML 非可视属性 `cNvPr@descr`（替换文字；为空时回退 `title`），兼容 Excel 的 `_x000D_` 转义。写成 `z=0.5x` 时长方体高度 = X 宽度 × 0.5；`z=0.1y` 时高度 = Y 高度 × 0.1。可见文字 `B1_x0.5` 不再决定高度。替换文字不存在或无效则**不绘制长方体**，保留可见、可点击的平面图元。同一 Sheet 仍禁止面积重叠的矩形，允许仅共边/顶点。
- **椭圆的 Z 定位**：椭圆中心落在某个矩形的旋转后二维占地区域时，将椭圆平面抬升到该矩形的 Z 顶部；重叠矩形取**最高的顶部**。圆形仍可被 Raycaster 点击。
- 其余对象保留原来的平面覆盖层。

**现在只有文本框在左侧 Three.js 画布上恢复绘制正文文字**，矩形和椭圆等非文本框仍不增加文字纹理。文本框文字样式既可用于视觉展示，也用于原有几何层级与 SVG 检索。字体取自 XLSX 的单段运行属性、段落默认属性或主题字体配置；缺失时回退系统字体。文字以纹理形式绘制并随形状的几何坐标与旋转同步；不依赖任何额外字体下载。对于 Excel 特殊竖排、复杂文字路径或文本自动缩放效果，仍需实际图纸视觉核对。`z=0.5x` 的长方体高度规则保持不变。

浏览器标签使用 XLSX 文件名但**不显示末尾 .xlsx 后缀**，例如 `luoD.xlsx` 显示为 `luoD`；其他带点字符的文件名部分保持不变。

## 页面可调分割

左侧 CAD 与右侧 SVG 之间的**竖向分割条**可拖动，两侧容器实时改变大小；右侧两幅 SVG 中间的**横向分割条**也可拖动，调整上下区域高度。均支持键盘方向键微调。

右侧默认 SVG 仍为 `PSD_base.svg` 与 `1-3-Octave_base.svg`，保留原图长宽比和中心对齐。初始左右水平分隔线同高度（1:1）。**右侧上下图片独立计算最大缩放**，用 `min(容器宽度, 容器高度 / SVG宽高比)` 获取每栏允许的最大图片宽度；若高度成为限制条件，以高度为准，反之以宽度为准。叠加 SVG 也参与本栏限幅，确保显示完整、不产生横向滚动条。

右侧浮动 legend 中的每条记录均保持 **14px 粗体、左对齐**；右键菜单的一级选项（“颜色”、“退出”）也以统一宽度左对齐，不修改二级颜色列表的纵向排列。

## SVG 只读与内存改色

`/viewer/assets/` 仅用于**读取原始 SVG**；动态颜色只存在于浏览器当前页面的 Blob 图片中，关闭项目或重载页面后不会写回本地 SVG。为避免多次读取和重复解析，原始 SVG 文本按 URL 缓存在本页内存中；更换颜色会对同一原始文本重新着色，并释放被替换的 Blob URL。已删除 `svg_styling.py`、服务端 `/viewer/cad-svg-style` 写入路由、线宽与线型菜单及相关文件修改逻辑。

## 双轨验证

```bash
python tests/run_tests.py
```

与 `.github/workflows/test.yml` 使用相同的 unittest 测试组，分别由 Ubuntu/Python 3.12 和 Windows/Python 3.14 运行，并验证 `cad_viewer.js` 的模块语法。新增 XLSX alt/title 属性测试、BODYv2 子目录时间戳与成对图片安全匹配测试、图像比例尺与分隔条限位测试。测试覆盖图纸解析、零点转换、图片唯一性、形状分类、矩形 X/Y 高度后缀、旋转矩形面积重叠校验、圆与矩形的完全包含/部分相交/完全分离及多矩形相交终止、网页静态资源、两处拖动布局和 Bokeh 旧接口。另使用 `node --test tests/test_cad_geometry.mjs tests/test_cad_ui.mjs` 对实际浏览器共享的几何、层级选中与响应式 SVG 适配算法执行独立 JS 单元测试。通过与失败都自动生成并上传 `test_report.md`；main 的自动报告回写不会再次触发 CI。

**真实 XLSX 内嵌图片与图元的相对位置，以及右侧两张 SVG 的叠加效果仍需要 Windows 浏览器视觉验证**，CI 无法代替实际资源检查。
